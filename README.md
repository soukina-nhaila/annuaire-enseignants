# Annuaire des enseignants

Mini-projet DEVOPS II, Groupe 12
Faculté Polydisciplinaire de Larache, Université Abdelmalek Essaâdi

## Description

Application web en lecture seule permettant de consulter l'annuaire des
enseignants d'un département, de rechercher un enseignant et d'afficher sa
fiche détaillée.

## Stack

- Frontend : React + Vite
- Backend : Python + Flask (API REST)
- DevOps : Docker, Kubernetes, NGINX Ingress, GitHub Actions, Nagios Core
